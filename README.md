---

## 🌟 特色功能

### 核心玩法
| 系统 | 说明 |
|------|------|
| **境界修炼** | 练气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫，九大境界逐步突破 |
| **战斗系统** | HP/MP/ATK/暴击/防御 真实计算，支持 PVP（切磋/决斗）和 PVE |
| **神通系统** | 87个主动战斗技能（攻击/增益/持续/控制），单槽装备，战斗自动触发 |
| **宗门系统** | 创建/加入宗门，职位管理，宗门建设与捐献，宗门任务 |
| **世界Boss** | 全服Boss降临，多人合力讨伐，按伤害排名瓜分奖励 |
| **秘境探索** | 挂机式秘境探索，获取灵草与稀有丹药 |
| **历练系统** | 4条路线（巡山/云游/猎魔/九死一生），离线挂机获取收益 |
| **炼丹系统** | 收集材料炼制丹药，提升修为或增加属性 |
| **传承系统** | 传承挑战争夺Buff加成，传承排行榜竞技 |
| **成就系统** | 自动解锁成就，装备展示称号 |

### 独有系统
| 系统 | 说明 |
|------|------|
| **🏔️ 洞天福地** | 个人修炼空间，5档洞天可选，持续产出灵石和修为 |
| **🌾 灵田种植** | 开垦灵田种植灵草，8种灵草不同收益周期 |
| **💕 双修系统** | 与他人双修互增修为（各获1%修为之和），龙虎丹可翻倍 |
| **👁️ 天地灵眼** | 抢占灵眼提升闭关修炼效率，PVP资源争夺玩法 |
| **🤝 玩家交易** | 群内面对面即时交易，双方放入物品/灵石后各自确认，物品/灵石托管原子结算 |
| **🏪 寄售行** | 全局寄售市场，离线挂单成交，5% 上架手续费，7 天未售出自动退回 |
| **🏦 灵石银行** | 0.1%日复利存款，VIP会员体系，贷款系统（逾期追杀） |
| **📜 悬赏任务** | 每日2条多难度悬赏，预锻法奖励与动态掉落率 |

## 📜 指令大全

> 共计 **100+** 条注册指令，以下按系统分类列出。指令前加 `/` 使用，如 `/我要修仙`

### 📖 入门 & 基础
| 指令 | 说明 |
|------|------|
| `我要修仙 [灵修/体修]` | 创建角色，灵修擅法术，体修擅肉身 |
| `我的信息` | 显示境界、修为、战力、装备等完整面板 |
| `签到` | 每日领取灵石(50-500) |
| `改道号 <名称>` | 修改你的仙道称号（2-12字） |
| `重铸灵根` | 花费25万灵石重新随机灵根 |
| `弃道重修 [确认]` | 删除角色并清空数据，7天内仅可执行一次，需追加"确认" |

### 🧘 修炼突破
| 指令 | 说明 |
|------|------|
| `闭关` | 开始闭关修炼，离线也可积累修为（上限15天） |
| `出关` | 结算闭关时间，获取对应修为 |
| `突破信息` | 查看当前境界突破所需修为、成功率、风险 |
| `突破 [丹药名]` | 尝试突破，可服用丹药增加成功率，失败损失0.1%~1%修为，有概率死亡 |

### 🎒 装备丹药
| 指令 | 说明 |
|------|------|
| `我的装备` | 显示已装备的武器/防具/心法/神通及属性加成 |
| `装备 <名>` | 从储物戒装备到身上（武器/防具/心法/神通） |
| `卸下 <名>` | 卸下装备放回储物戒 |
| `丹药背包` | 查看拥有的丹药及效果（合并到储物戒显示） |
| `服用丹药 <名> [数量]` | 使用丹药获得增益，支持批量服用 |
| `丹药信息 <名>` | 查看丹药详细信息（品阶/类型/效果/使用限制） |

### 🔮 神通系统
装备1个神通，战斗中按概率自动触发，消耗MP并进入冷却

| 指令 | 说明 |
|------|------|
| `神通列表` | 浏览所有神通（按攻击/增益/持续/控制分类） |
| `我的神通` | 查看已装备的神通详情 |
| `装备神通 <名>` | 从储物戒装备神通 |
| `卸下神通` | 卸下当前神通放回储物戒 |
| `神通信息 <名>` | 查看神通详情（品阶/类型/效果/MP消耗/冷却/触发率） |

### 🏪 商店系统
| 指令 | 说明 |
|------|------|
| `丹阁` | 丹药专卖(破境丹/修为丹/功能丹)，定时自动刷新 |
| `器阁` | 装备专卖(武器/防具/饰品)，定时自动刷新 |
| `百宝阁` | 综合商店(功法/材料/杂物)，定时自动刷新 |
| `购买 <物品名> [数量]` | 从当前商店购买物品，支持 `x10` 或空格数量语法 |
| `查看 <名称>` | 查看任意物品的详细信息（数值/品阶/效果） |
| `物品信息 <名称>` | 查询在售物品/丹药的效果与获取途径 |

### 📦 储物戒系统
物品中央枢纽，购买/掉落/收获的物品自动存入

| 指令 | 说明 |
|------|------|
| `储物戒` | 查看储物空间和物品（分类显示：装备/材料/功法/丹药/其他） |
| `搜索物品 <关键词>` | 模糊搜索储物戒物品 |
| `炼金 <物品名> [数量]` | 将物品转化为灵石（市场价20%） |
| `丢弃 <物品名>` | 永久丢弃储物戒中的物品 |
| `更换储物戒 <名称>` | 升级储物戒（需灵石，提升容量） |
| `赠予 <@某人> <物品> [数量]` | 将物品赠送给其他玩家（24小时有效期） |
| `接收` | 接收他人赠予的物品 |
| `拒绝` | 拒绝赠予请求（物品退还给发送者） |

### 🏦 灵石银行
0.1%日复利，逾期追杀

| 指令 | 说明 |
|------|------|
| `银行` | 查看存款余额、VIP等级、利率、利息和贷款状态 |
| `存灵石 <数量>` | 存入灵石（上限10亿），开始计息 |
| `取灵石 <数量>` | 取出存款 |
| `领取利息` | 每日可领一次利息 |
| `贷款 <金额>` | 普通贷款(0.5%日利率，7天，10万~1亿) |
| `突破贷款 <金额>` | 短期贷款(0.8%日利率，3天，突破成功自动还款) |
| `还款` | 偿还当前贷款（本金+利息） |
| `银行流水` | 查看最近交易记录 |
| `升级会员` | 升级银行VIP会员等级（享受更高利率） |

### 📜 悬赏任务
| 指令 | 说明 |
|------|------|
| `悬赏令` | 查看当期多难度悬赏（显示风险/目标/奖励/说明），每日限2次 |
| `接取悬赏 <编号>` | 接取指定任务（每日限2次），限时内完成对应目标 |
| `悬赏状态` | 查看任务进度、剩余时间和奖励 |
| `完成悬赏` | 提交任务领取灵石/修为/掉落 |
| `放弃悬赏` | 取消当前任务（30分钟冷却） |

> 悬赏进度通过对应标签的活动累计：巡山/云游/猎魔等历练路线会提供不同"冒险标签"，秘境探索也能推进探索类悬赏。

### 🤝 玩家交易（即时面对面）
| 指令 | 说明 |
|------|------|
| `交易 <@某人>` | 在当前群发起交易请求，仅可在群聊中使用 |
| `接受交易` | 接受他人发来的交易请求，正式进入交易状态 |
| `拒绝交易` | 拒绝交易请求 |
| `添加物品 <名称> [数量]` | 把背包/储物戒/丹药中的物品放入交易（即时托管） |
| `添加灵石 <数量>` | 把灵石放入交易托管 |
| `移除物品 <名称>` | 取回放入的物品，物品自动回到原来的库存 |
| `查看交易` | 查看双方放入的物品/灵石以及确认状态 |
| `确认交易` | 确认当前交易；双方都确认后立即原子结算 |
| `取消交易` | 任一方可取消，物品/灵石全部退还 |

> 任何添加/移除操作都会**清空双方的确认状态**，避免一方偷改后另一方未察觉直接成交。
> 交易超时（默认 30 分钟）未完成会自动取消并退还所有托管。

### 🏪 寄售行（异步挂单）
| 指令 | 说明 |
|------|------|
| `寄售 <物品名> <价格> [数量]` | 上架物品，扣除卖家 5% 灵石作为上架手续费（**不退还**） |
| `寄售行 [页码]` | 浏览全局寄售行，分页显示 |
| `购买寄售 <编号>` | 一口价购买指定编号物品，灵石全额转入卖家 |
| `我的寄售` | 查看自己当前所有在售的物品 |
| `下架寄售 <编号>` | 主动下架，物品退回背包；手续费不退 |

> 未售出物品 **7 天后自动下架**并退回卖家库存（手续费已消耗）。
> 同一物品同时只能被一个买家购入，并发购买自动安全。
> 寄售浏览、购买、上架在闭关/历练/秘境等状态下也允许使用，便于挂机赚钱。

## 🔧 GM管理员指令
管理员专属，支持群聊（@人）和私聊（QQ号），需要在配置中设置 BOSS_ADMINS。

| 指令 | 说明 |
|------|------|
| `GM指令帮助` | 查看GM指令帮助 |
| `GM加灵石 <目标> <数量>` | 为目标玩家增加灵石 |
| `GM扣灵石 <目标> <数量>` | 扣除目标玩家灵石 |
| `GM加修为 <目标> <数量>` | 为目标玩家增加修为 |
| `GM设置境界 <目标> <等级>` | 设置目标玩家境界等级 |
| `GM加物品 <目标> <物品名> [数量]` | 向目标储物戒添加物品 |
| `GM扣物品 <目标> <物品名> [数量]` | 从目标储物戒移除物品 |
| `GM加丹药 <目标> <丹药名> [数量]` | 向目标丹药背包添加丹药 |
| `GM扣丹药 <目标> <丹药名> [数量]` | 从目标丹药背包移除丹药 |
| `GM查看玩家 <目标>` | 查看目标玩家完整信息 |
| `GM刷新秘境` | 强制刷新秘境并重置所有玩家探索次数 |
| `GM补偿 <物品 数量\|物品 数量>` | 创建全服补偿包（用 `\|` 分隔多个物品） |
| `禁用物品 <物品名>` | 禁用指定物品（从商店下架） |
| `启用物品 <物品名>` | 重新启用被禁用的物品 |

## ⏰ 后台任务

插件启动后自动运行 8 个后台任务：

| 任务 | 周期 | 说明 |
|------|------|------|
| Boss自动生成 | 1小时（可配置） | 按配置间隔自动刷新世界Boss |
| 贷款逾期检查 | 1小时 | 检查逾期贷款，追杀违约玩家 |
| 灵眼刷新 | 4小时 | 生成新灵眼 + 清理过期灵眼 |
| 悬赏过期检查 | 30分钟 | 过期未完成的悬赏自动取消 |
| 寄售过期检查 | 1小时 | 7天未售出物品自动退回卖家 |
| 交易超时检查 | 5分钟 | 30分钟未完成的交易自动取消并退还 |
| 秘境每日广播 | 每日12:00 | 广播今日开放的秘境信息 |
| 商店自动刷新 | 6小时 | 自动刷新丹阁/器阁/百宝阁商品并广播 |

> 所有后台任务使用指数退避重试机制，数据库断连后自动恢复。
