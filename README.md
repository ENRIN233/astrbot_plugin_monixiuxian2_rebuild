## 🌟 特色功能

### 🌟 奇遇机缘
修炼途中随机触发的机缘事件：**62 种事件 / 138 个选项**，按 6 大境界段 × 4 档稀有度分布。签到（15%）、出关（10%）、秘境（20%）、悬赏（25%）、世界Boss（30%）、灵田播种（8%）与收取（10%）均有概率触发；**传说级奇遇将全服匿名广播**。

| 指令 | 说明 |
|------|------|
| `奇遇 <选项>` | 回复当前奇遇的选择（A/B/C，180秒内有效） |
| `奇遇信息` | 查看因果值、称号与今日奇遇次数 |
| `奇遇记录` | 查看最近的奇遇经历 |

> ⚖️ **因果值**（-1000 ~ +1000）影响奇遇成败判定，并为战斗/修炼提供 ±4%/8% 加成；善恶终有报，恶行失败同样折损因果。
