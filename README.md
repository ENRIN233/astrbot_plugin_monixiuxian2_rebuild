## 🌟 特色功能

### 核心玩法
| 系统 | 说明 |
|------|------|
| **境界修炼** | 58级修炼体系（19大境界 × 3子阶段 + 1起始），灵修/体修双路线 |
| **战斗系统** | HP/MP/ATK/暴击/穿透/吸血/防御全面计算，支持 PVP（切磋/决斗）和 PVE |
| **神通系统** | 53个主动战斗技能（攻击/持续/增益/控制），单槽装备，战斗自动触发 |
| **宗门系统** | 创建/加入宗门，职位管理，宗门建设与捐献，攻击修炼，丹房，每日资材发放 |
| **世界Boss** | 20档全服Boss，1小时自动刷新，多人合力讨伐，4档材料掉落 |
| **锻造系统** | 52个锻造配方（33武器+19防具），4品质等级，随机词条，分解回收 |
| **炼丹系统** | 49种配方，寒热调和机制，收集材料炼制丹药 |
| **辅修功法** | 23种战斗辅助技能，13种 buff 类型（ATK%/暴击/暴伤/回血/吸血/破甲等） |
| **传承系统** | 传承挑战争夺 buff 加成，传承排行榜竞技 |

### 经济与交互
| 系统 | 说明 |
|------|------|

## ⚙️ 配置说明

插件首次运行后，将在 `config/` 目录下自动生成默认配置文件：

| 配置文件 | 作用 |
|----------|------|
| `game_config.json` | 全局游戏参数（签到范围、闭关上限等） |
| `level_config.json` | 境界属性表（58级修为需求、成功率、属性增益） |
| `items.json` | 物品/材料/功法数据库（79主修心法） |
| `weapons.json` | 武器数据库（66武器 + 38防具） |
| `skills.json` | 神通技能数据库（53个技能） |

## ⏰ 后台任务

插件启动后自动运行 8 个后台任务：

| 任务 | 周期 | 说明 |
|------|------|------|
| Boss自动生成 | 1小时（可配置） | 按配置间隔自动刷新世界Boss |
| 贷款逾期检查 | 1小时 | 检查逾期贷款，追杀违约玩家 |
| 悬赏过期检查 | 30分钟 | 过期未完成的悬赏自动取消 |
| 寄售过期检查 | 1小时 | 7天未售出物品自动退回卖家 |
| 交易超时检查 | 5分钟 | 30分钟未完成的交易自动取消并退还 |
| 秘境每日广播 | 每日12:00 | 广播今日开放的秘境信息 |
| 宗门资材发放 | 每日11:00 + 12:00 | 按建设度×10%自动发放 |
| 宗门自动传位 | 每日检查 | 宗主离线7天自动传位 |

> 所有后台任务使用指数退避重试机制，数据库断连后自动恢复。
