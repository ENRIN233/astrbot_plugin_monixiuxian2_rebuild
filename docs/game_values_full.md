## 十八、战斗公式

### 18.1 属性计算

```
基础血量 = 修为 / 2
基础真元 = 修为
实际血量 = 基础血量 × (1 + 血量buff)
实际真元 = 基础真元 × (1 + 真元buff)
```

### 18.2 攻击计算

```
基础攻击 = 修为 / 10
修炼加成 = 修炼等级 × 4%
总攻击 = 基础攻击 × (1 + 修炼加成 + 攻击buff)
```

### 18.3 回合伤害

```
基础伤害 = 总攻击 × random(0.95, 1.05) × (1 + 攻击buff)
暴击判定 = random(0, 100) ≤ 暴击率 → 伤害 × 1.5
防御减伤 = 防御 / (防御 + 100)
最终伤害 = max(1, 基础伤害 × (1 - 防御减伤))
```
