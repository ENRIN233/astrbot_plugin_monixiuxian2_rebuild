3. **零社交**：园子与群友完全无关；
4. **零风险**：收菜无悬念，炼丹原料曲线平坦。

## 1. v2 设计目标

| 目标 | 手段 |
|------|------|
| **回访锚点** | 成熟窗口 = 黄金回访点；枯萎窗口 = 温和紧迫感 |
| **代理感** | 播种自选作物（复用 herbs.json 108 种药材） |
| **社交钩子** | 偷菜（恶）+ 护园灵兽（防）+ 被偷记录（恩怨簿） |
| **经济沉淀** | 种子灵石消耗 + 催熟加速，双向 gold sink |
| **系统联动** | 因果值（偷菜扣 karma）、奇遇触发点、活跃度任务、炼丹供应链 |
| **平滑迁移** | 未播种地块自动进入"野生模式"，收益与现状持平，老玩家零损失 |

## 2. 核心循环（v2）

```
播种(选作物+花灵石买种) → 生长(12~48h，三阶段可视)
    → 成熟窗口(12~24h 完美期) ←—— 黄金回访点
        → /灵田收取 收入储物戒
        → 或被群友 /偷菜 盯上 → 护园灵兽拦截
    → 过熟枯萎(每12h −25%~30% 产量) ←—— 温和压力
        → 48h 后枯死 → /灵田清理
收获/播种 +灵植经验 → 园圃等级 → 解锁枯萎免疫/产量加成/高档种子
```

## 3. 地块模型（v2 核心）

### 3.1 每块田独立地块状态

现有"全田一个冷却"升级为**逐块管理**。`herb_fields` 块田各自独立：

```
地块状态机: 空地 → 野生生长 / 播种生长 → 成熟 → 过熟 → 枯死 → (清理) → 空地
```

- **空地**：可 `/灵田播种`；若一直不播种，24h 后自动进入野生生长（详见 §3.3）。
- **播种生长**：按所选作物的生长时长走三阶段。
- **野生生长**：无需种子，随机长一种境界内药材，生长 48h（与现收益持平）。

### 3.2 生长阶段显示

`/灵田` 视图改为地块矩阵：

```
🌾 我的灵田（园圃 Lv.2）
━━━━━━━━━━━━━━━
① 恒心草  🌱 萌芽  ▓░░░░░░░░░ 3h/12h
② 紫猴花  🌿 生长  ▓▓▓▓▓░░░░░ 14h/24h
③ 龙涎草  ✨ 成熟  ⏰ 完美期剩余 9h
④ 血琥珀  🥀 过熟  产量 −25%
⑤ 野生    🌿 生长  ▓▓▓░░░░░░░ 18h/48h
⑥ 空地    （24h 后自行野生）
━━━━━━━━━━━━━━━

💡 /灵田播种 <药材名> | /灵田收取 | /偷菜 @某人
```

### 3.3 野生模式（老玩家零损失的关键）

- 未播种空地 24h 后自动长出随机药材（rank 池同现有 `_get_player_harvest_rank` 过滤），生长 48h，成熟产 **1 株**。
- **收益对齐验证：** 现状 6 田 → 48h 收 6+收取等级 株；v2 全野生 → 6 田各 48h 产 1 株 = 6 株 + 收取等级加成 → **持平**。
- 播种是**增量优化**：花灵石买种、投入注意力（防枯防盗），换更高产量 —— 玩家自愿升级，而非被迫迁移。

## 4. 播种系统

### 4.1 作物表 `config/garden_crops.json`

复用 `herbs.json` 108 种药材，按 rank 门槛分 5 档：

| 档位 | rank 门槛 | 生长时长 | 种子成本 | 产量 | 完美窗口 | 枯萎步长 |
|------|-----------|----------|----------|------|----------|----------|
| 一档（凡品） | ≥48 | 12h | 5 万 | 1~2 | 24h | 每 12h −25% |
| 二档 | ≥40 | 24h | 25 万 | 2 | 24h | 每 12h −25% |
| 三档 | ≥32 | 24h | 80 万 | 2~3 | 18h | 每 12h −25% |
| 四档 | ≥24 | 36h | 200 万 | 3 | 18h | 每 12h −30% |
| 五档 | ≤20 | 48h | 500 万 | 3~4 | 12h | 每 12h −30% |

- `rank 门槛` 与现有收取 rank 阈值同源：玩家境界不够时高档种子不可购买（`/灵田播种 血琥珀` → "你的境界尚无法驾驭此等灵植"）。
- **上线前校验脚本要求：** 对每档抽 3 种药材，验证 `产量 × 药材市价均值 ≥ 1.5 × 种子成本`（ROI 下限 1.5，防止种了亏本）；上限自然受产量封顶，预计 ROI ∈ [1.5, 2.5]。
- 长周期作物单位时长收益略优、但资金占用久 + 枯萎/被偷风险敞口大 —— 风险收益自平衡。

### 4.2 播种命令

```
/灵田播种 血琥珀        → 播到第一块空地
/灵田播种 血琥珀 全部   → 播满所有空地（每块各扣一次种子钱）
```

- 播种即扣种子灵石（gold sink）；失败场景：无空地 / 境界不足 / 灵石不足 / 药材名不在作物表。
- 播种 +5 灵植经验。

### 4.3 枯萎机制（温和压力，不做惩罚陷阱）

```
成熟 → 完美窗口（12~24h，产量 100%）
     → 过熟期：每 12h 产量 −25%/−30%（分段衰减，下限 40%）
     → 过熟 48h：枯死（种子沉没，产量归零）
     → /灵田清理（免费）回到空地
```

- 枯萎**只减产不清田**（48h 内仍可收），惩罚温和；
- 园圃 Lv.2 后完美窗口 +6h，Lv.3 野生地块免疫枯萎 —— 成长感直接对冲焦虑感。

### 4.4 催熟（可选加速，灵石 sink）

```
/灵田催熟 → 将所有"生长中"的种植地块立即推至成熟
费用 = 剩余生长时长 × 10 万/h，向上取整，最低 15 万
```

典型用法：早晨播种 24h 作物，晚上花 ~120 万催熟当晚炼丹 —— 把"等"变成"花钱"的合法出口。

## 5. 收取 v2

`/灵田收取` 语义升级：**收走全部已成熟地块**（含野生），未成熟不动。

- 每块产量 = 作物基础产量 × 枯萎系数；全田额外 `+收取等级`（harvest_level Lv.0~3，现有加成保留）与功法 `harvest_bonus`（现有逻辑保留），加成株按境界池随机补入。
- 收取后地块回到**空地**（24h 后自动野生）。
- 冷却模型变化：废除全田 `last_harvest_time` 单冷却，改由地块各自 `planted_at + growth_hours` 驱动（迁移方案 §9.3）。
- 触发活跃度 `track_harvest`（现有）；触发奇遇 `try_trigger(player, "harvest")` 10%（奇遇 v3 §1.2）。

## 6. 偷菜社交（v2 灵魂）

### 6.1 命令与规则

```
/偷菜 @某人     （或直接回复对方消息发 /偷菜）
```

| 规则项 | 取值 | 说明 |
|--------|------|------|
| 可偷对象 | 同群已注册玩家 | 无灵田者提示"TA 还没有灵田" |
| 可偷地块 | 仅**成熟**地块（完美期/过熟均可） | 生长中偷不得，"灵植未熟，灵气反噬" |
| 偷取量 | 1 株/次（对方该地块产量 −1，产量保底 1） | 真实损失，制造恩怨 |
| 小偷频次 | 3 次/日 | 防刷 |
| 被偷频次 | 5 次/日 | 保底尊严，超出后"园子灵气自行封闭" |
| 因果代价 | **karma −1/次** | 恶行记账，直接联动奇遇因果体系（v2 §4）—— 偷多了变"偏邪"，挨魔道事件 |
| 记录 | 双方各记一笔：小偷得药材，失主恩怨簿 +1 | 失主下次 `/灵田` 可见"被偷 2 次（名单）" |

### 6.2 护园灵兽（防偷博弈）

购买/升级（灵石一次性投入，拦截时反获收益）：

| 等级 | 费用 | 拦截率 | 拦截效果 |
|------|------|--------|----------|
| 无兽 | — | 0% | — |
| 灵犬 Lv.1 | 300 万 | 15% | 小偷被逮：罚款 50 万灵石（失主得 50%），小偷 karma **−2** |
| Lv.2 | +200 万 | 25% | 同上 |
| Lv.3 | +500 万 | 35% | 同上 |

- 命令：`/护园`（查看）、`/护园 升级`；兽蛋也可来自传说级群体奇遇窗口掉落（30%，见奇遇 v3 §2.5），此类蛋孵出即为 Lv.1 且免 300 万费用 —— 跨系统钩子。
- 拦截发生时群内播报一行（"🐕 灵犬一声长啸，夜半摸金客抱头鼠窜，被罚 50 万灵石！"）—— 偷与防都成为**群内公共事件**，社交价值大于数值价值。

### 6.3 偷菜经济学

- 小偷收益：1 株药材（市价均值 ~20~50 万按档）− karma −1 − 15~35% 概率倒罚 50 万；
- 失主损失：产量 −1（保底 1）→ 单次被偷损失 ≈ 一株药材，远小于被气到的情绪价值；
- 期望净收益略正但不暴利，**恩怨与播报才是奖励**。

## 7. 园圃等级（灵植养成线）

种植/收获积累 `garden_exp`：播种 +5 / 收取 +10。

| 园圃等级 | 所需累计经验 | 解锁 |
|----------|--------------|------|
| Lv.1 | 0（初始） | 基础玩法 |
| Lv.2 | 200 | 完美窗口 +6h；解锁二档种子 |
| Lv.3 | 600 | 野生地块免疫枯萎；解锁三档种子 |
| Lv.4 | 1500 | 全田产量 +10%（四舍五入）；解锁四档种子 |
| Lv.5 | 3000 | 解锁五档种子；收取时 10% 概率双倍 |

- 与境界 rank 门槛**叠加生效**（两个都要满足）；
- 与 `harvest_level`（炼丹经验线）并行不冲突：一条管"种得好在哪"，一条管"收得多多少"。

## 9. 数据模型

### 9.1 migration v43（`LATEST_DB_VERSION = 43`）

```python
@migration(43)
async def v43_spirit_garden_v2(conn, config_manager):
    """v43: 灵植园 v2 —— 地块/园圃/灵兽"""
    for col in (
        "plots TEXT DEFAULT '[]'",           # 地块 JSON
        "garden_exp INTEGER DEFAULT 0",
        "garden_level INTEGER DEFAULT 1",
        "beast_level INTEGER DEFAULT 0",     # 0=无兽
        "steal_out_today INTEGER DEFAULT 0",  # 今日已偷次数
        "steal_in_today INTEGER DEFAULT 0",   # 今日被偷次数
        "daily_counter_date TEXT DEFAULT ''", # 频次日期
        "grudge_log TEXT DEFAULT '[]'",       # 恩怨簿（最近10条）
    ):
        try:
            await conn.execute(f"ALTER TABLE spirit_farms ADD COLUMN {col}")
        except Exception:
            pass  # 列已存在
```

### 9.2 plots JSON 结构

```json
[
  {"slot": 1, "herb_id": "herb_017", "herb_name": "血琥珀", "mode": "planted",
   "planted_at": "2026-09-21 08:00:00", "growth_hours": 36,
   "perfect_window_hours": 18, "wither_step_pct": 30, "yield_min": 3, "yield_max": 3},
  {"slot": 2, "herb_id": "auto", "herb_name": "", "mode": "wild",
   "planted_at": "2026-09-20 22:00:00", "growth_hours": 48,
   "perfect_window_hours": 24, "wither_step_pct": 25, "yield_min": 1, "yield_max": 1}
]
```

- 状态不落库、读取时按 `planted_at + growth_hours` 实时推导（萌芽/生长/成熟/过熟/枯死），**无后台任务**，与本项目"惰性计算"惯例一致；
- `slot` 数量上限仍由 `herb_fields`（1~6）约束。

### 9.3 数据迁移细则（防收益跳变）

迁移时为每个现有农场按 `last_harvest_time` 的剩余冷却折算生成等量野生地块：
`planted_at = now − (48h − 剩余冷却)` → 玩家等待节奏完全不变，无"迁移即白嫖/重等"。

## 11. 数值平衡验证

### 11.1 收益对比（满配 6 田 / 48h 周期 / 元婴期）

| 方案 | 产出 | 灵石净流 | 玩家操作 |
|------|------|----------|----------|
| 现状（纯收取模型） | 6~9 株随机 | +0 sink | 1 次/48h |
| v2 全野生 | 6~9 株随机 | +0 sink | 1 次/48h（持平 ✅） |
| v2 全播种三档 | 12~18 株自选 | −480 万种子 (+sink) | 播 1 + 收 1 /24h |
| v2 全播种五档 | 18~24 株自选 | −3000 万种子 | 播 1 + 收 1 /48h |

- 播种收益上浮 ~2 倍但**吃掉种子成本 + 催熟费**，实际灵石净增量收敛在 +30~60%，且全部换来的是玩家最缺的**药材自选权**（定向补炼丹短板）；
- 日均回访点：播种流 2 个（播种+收取），野生流 1 个 —— 全体玩家回访频率不降，活跃玩家翻倍。

### 11.2 偷菜总量守恒

每群每日偷取上限 = 活跃小偷数 × 3 次 × 1 株，且被偷方 5 次封顶 → 全群日药材流失 < 日产出的 8%，不伤经济根本。
